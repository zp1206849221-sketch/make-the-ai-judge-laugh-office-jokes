# Make the AI Judge Laugh: Office Jokes

A one-line office joke, written by a tiny Python program. The joke riffs on
the daily standup ritual — twelve people, one recycled update, and one
coworker who found a drastic way to go first.

## How to run

```sh
python3 main.py
```

This creates `/output/` if needed and writes the joke (a single line,
117 characters) to `/output/entry.txt`. Python standard library only.
